1. Definition1. Định nghĩa

IWR is the alias (short name) of the Invoke-WebRequest cmdlet in PowerShell. It sends an HTTP/HTTPS request to a URL and returns the content — you can save it to a file, or read the text, headers, status code directly...

IWR là alias (tên gọi tắt) của cmdlet Invoke-WebRequest trong PowerShell. Nó gửi yêu cầu HTTP/HTTPS tới một URL rồi trả về nội dung — có thể lưu ra file, hoặc đọc thẳng text, header, status code...

Analogy: If certutil is the "registry clerk" who carries a parcel as a side favour, then Invoke-WebRequest is the "professional courier": it fills in the form (headers), shows credentials (auth), passes through transit hubs (proxy) and unpacks the parcel (parses HTML) all the way to its destination.
Ví von: Nếu certutil là "nhân viên hộ tịch" tiện tay xách giúp một kiện hàng, thì Invoke-WebRequest là "nhân viên giao vận chuyên nghiệp": biết điền phiếu (header), xuất trình giấy tờ (auth), đi qua trạm trung chuyển (proxy) và bóc tách bưu kiện (parse HTML) đến nơi đến chốn.

2. Basic syntax2. Cú pháp cơ bản

IWR -Uri http://host/file.bin -OutFile output.bin

Written out in full for clarity:

Viết đầy đủ cho dễ nhớ ý nghĩa:

Invoke-WebRequest -Uri "http://host/file.bin" -OutFile "output.bin"

3. Common variants3. Vài biến thể hay gặp

Lighter and faster RECOMMENDED

Tải nhẹ, nhanh hơn NÊN DÙNG

IWR by default tries to parse the page DOM (slow, sometimes errors). Turn it off for a lean fetch:

IWR mặc định cố phân tích DOM của trang (chậm, đôi khi lỗi). Tắt đi cho gọn:

IWR -Uri http://host/file.bin -OutFile output.bin -UseBasicParsing

Read the content now, without saving a file

Đọc nội dung ngay, không lưu file

Good when the URL returns text (e.g. grabbing a string shown directly):

Hợp khi URL trả về text (ví dụ nhặt một chuỗi hiển thị trực tiếp):

(IWR -Uri http://host/path -UseBasicParsing).Content

An older approach — WebClient

Cách cổ điển hơn — WebClient

Same .NET family, common in older docs:

Cùng họ .NET, hay gặp trong tài liệu cũ:

(New-Object System.Net.WebClient).DownloadFile("http://host/file.bin","output.bin")

Add headers / auth / proxy

Thêm header / auth / proxy

IWR -Uri https://host/api -Headers @{Authorization="Bearer xxx"} -OutFile data.json

This is where IWR far outstrips certutil: request customisation is very flexible.

Đây là điểm IWR vượt xa certutil: tùy biến request rất linh hoạt.

4. Blue-team view4. Góc blue team

PowerShell leaves more traces — if full logging is on

PowerShell để lại nhiều dấu vết hơn — nếu bật log đầy đủ

  • Script Block Logging (Event ID 4104) — records the full content of commands that ran, even when obfuscated.
  • Script Block Logging (Event ID 4104) — ghi lại toàn bộ nội dung lệnh đã chạy, kể cả khi bị làm rối (obfuscate).
  • Module Logging (Event ID 4103) — records which cmdlet was called and its parameters.
  • Module Logging (Event ID 4103) — ghi chi tiết cmdlet được gọi và tham số.
  • Transcription — saves the entire PowerShell session to a text file.
  • Transcription — lưu toàn bộ phiên PowerShell ra file text.

MITRE ATT&CK: T1105 (Ingress Tool Transfer), T1059.001 (Command and Scripting Interpreter: PowerShell).

MITRE ATT&CK: T1105 (Ingress Tool Transfer), T1059.001 (Command and Scripting Interpreter: PowerShell).

Analogy: IWR is like walking in the front door of a building full of cameras. Very convenient and powerful, but if the defenders have enough "cameras" on (the logs above) every step is recorded in full.
Ví von: IWR như đi cửa chính của một tòa nhà nhiều camera. Rất tiện và mạnh, nhưng nếu phòng thủ bật đủ "camera" (các loại log trên) thì mỗi bước đi đều được ghi hình đầy đủ.
