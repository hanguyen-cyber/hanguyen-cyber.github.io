01Tổng quan

Get-WinEvent là cmdlet PowerShell để đọc Windows Event Log: log đang chạy trên máy, hoặc file .evtx đã xuất ra. Room TryHackMe nhấn mạnh: Event Viewer chỉ lọc tốt theo Event ID và keyword, còn lọc bằng XML trên giao diện thì rườm rà và khó mở rộng. Dòng lệnh cho bạn kiểm soát chi tiết hơn nhiều.

🏭 Hình dung Event Log là kho hồ sơ khổng lồ của nhà máy. Event Viewer là đi bộ vào kho lật từng thùng. Get-WinEvent là gọi điện cho thủ kho: "Tìm cho tôi các phiếu loại 3, ghi cổng 4444, trong ngày hôm qua". Bạn càng mô tả chính xác (lọc sớm), thủ kho càng mang về ít giấy và càng nhanh.

03Ba cách lọc – chọn cách nào?

-FilterHashtable

Dễ đọc, dễ viết. Lọc theo LogName/Path, Id, Level, thời gian, và tên trường dữ liệu.

Dùng khi: lọc thông thường, hằng ngày.

-FilterXPath

Là cách room TryHackMe dùng. Lọc sâu vào EventData bằng biểu thức XPath.

Dùng khi: cần kết hợp nhiều điều kiện trên trường dữ liệu.

Where-Object

Lọc sau khi đã lấy sự kiện về. Chậm hơn nhưng hỗ trợ -like, -match (regex).

Dùng khi: cần tìm chuỗi con, regex.

⚠️ Nguyên tắc tốc độLọc ở nguồn (Hashtable/XPath) trước, rồi mới Where-Object trên tập đã thu nhỏ. Dùng Get-WinEvent | Where-Object trên log hàng triệu dòng sẽ rất chậm.

05-FilterXPath

5.1 Hiểu cấu trúc XML của một sự kiện

XPath là "địa chỉ" để chỉ tới một ô dữ liệu trong XML. Mỗi sự kiện Sysmon trông như sau (xem ở tab Details → XML View của Event Viewer):

<Event>
  <System>
    <EventID>3</EventID>                          ← */System/EventID
    <TimeCreated SystemTime="2021-01-05T02:21:32Z"/>
  </System>
  <EventData>
    <Data Name="UtcTime">2021-01-05 02:21:32.123</Data>
    <Data Name="Image">C:\Users\...\payload.exe</Data>
    <Data Name="DestinationPort">4444</Data>   ← Data[@Name="DestinationPort"]
  </EventData>
</Event>

5.2 Ba mẫu lọc cơ bản (từ room)

Lọc theoMẫu
Event ID*/System/EventID=<ID>
Tên trường XML*/EventData/Data[@Name="<Tên>"]
Giá trị dữ liệu*/EventData/Data=<Giá trị>

Ví dụ trong room, tìm kết nối mạng ra port 4444:

Get-WinEvent -Path C:\Users\THM-Analyst\Desktop\Scenarios\Practice\Hunting_Metasploit.evtx `
  -FilterXPath '*/System/EventID=3 and */EventData/Data[@Name="DestinationPort"] and */EventData/Data=4444'
⚠️ Điểm tinh tếMẫu trên nghĩa là "có trường DestinationPort" và "có bất kỳ trường nào bằng 4444". Nếu SourcePort là 4444 thì cũng khớp. Cách viết chặt hơn, gắn giá trị vào đúng trường: 
Get-WinEvent -Path .\Hunting_Metasploit.evtx `
  -FilterXPath "*[System[EventID=3] and EventData[Data[@Name='DestinationPort']='4444']]"

5.3 Mẫu XPath nâng cao

Mục đíchXPath
Nhiều Event ID*[System[(EventID=1 or EventID=3)]]
Trường bằng giá trị*[EventData[Data[@Name='Image']='C:\Windows\System32\cmd.exe']]
Sau một mốc thời gian (UTC)*[System[TimeCreated[@SystemTime>='2021-01-05T00:00:00.000Z']]]
Trong 1 giờ qua (ms)*[System[TimeCreated[timediff(@SystemTime) <= 3600000]]]
Kết hợp*[System[EventID=10] and EventData[Data[@Name='TargetImage']='C:\Windows\system32\lsass.exe']]
⚠️ Giới hạnXPath của Windows Event Log chỉ là tập con: không có contains(), starts-with(). Muốn tìm chuỗi con thì lọc thô bằng XPath trước, sau đó dùng Where-Object { $_.Message -like '*mimikatz*' }.
💡 Mẹo trích dẫnBọc XPath bằng nháy đơn '...' ở ngoài và nháy kép "..." ở trong (hoặc ngược lại). Trộn lẫn sai là lỗi phổ biến nhất.

06Đọc trường EventData

Cột Message chỉ hiện tóm tắt. Muốn lấy đúng từng trường (UtcTime, Image, DestinationIp…) để sắp xếp, so sánh hay xuất CSV, hãy chuyển sự kiện sang XML.

🏭 Hình dungMột sự kiện giống phiếu nhập kho. Message là phần tóm tắt chép tay; ToXml() là bản gốc có từng ô ghi rõ "Tên ô: Giá trị".
# Biến mỗi sự kiện thành một object có đủ cột
function ConvertTo-SysmonObject {
  process {
    $x = [xml]$_.ToXml()
    $o = [ordered]@{ EventId = $_.Id; TimeCreated = $_.TimeCreated }
    foreach ($d in $x.Event.EventData.Data) { $o[$d.Name] = $d.'#text' }
    [pscustomobject]$o
  }
}

Get-WinEvent -FilterHashtable @{ Path='.\Filtering.evtx'; Id=3 } -Oldest |
  ConvertTo-SysmonObject |
  Select-Object UtcTime, Image, SourceIp, DestinationIp, DestinationPort -First 5 |
  Format-Table -AutoSize
CầnCách
Xem nhanh một sự kiện đầy đủ$e | Format-List * hoặc $e.Message
Trường theo vị trí$e.Properties[0].Value (vị trí khác nhau theo từng Event ID, dễ nhầm)
Trường theo tên (khuyên dùng)Hàm ConvertTo-SysmonObject ở trên
Thống kê... | Group-Object DestinationIp | Sort Count -Desc
Xuất CSV... | Export-Csv out.csv -NoTypeInformation
💡 Về thời gianTimeCreated hiển thị theo giờ máy local. Trường UtcTime trong EventData mới là giờ UTC. Room hỏi "UTC time" thì đọc UtcTime, không đọc cột TimeCreated.

07Công thức săn tìm theo kịch bản

Đặt sẵn biến cho gọn: $log = 'Microsoft-Windows-Sysmon/Operational' (hoặc dùng -Path với file .evtx).

A. Metasploit / reverse shell

Event 3T1571 
Get-WinEvent -LogName $log -FilterXPath "*[System[EventID=3] and EventData[Data[@Name='DestinationPort']='4444' or Data[@Name='DestinationPort']='5555']]"

B. Mimikatz đọc bộ nhớ LSASS

Event 10T1003.001 
Get-WinEvent -LogName $log -FilterXPath "*[System[EventID=10] and EventData[Data[@Name='TargetImage']='C:\Windows\system32\lsass.exe']]" |
  ConvertTo-SysmonObject | Select UtcTime, SourceImage, GrantedAccess

Chú ý SourceImage lạ và GrantedAccess như 0x1010, 0x1410, 0x1FFFFF.

C. Tìm file mimikatz được tạo ra

Event 11 
Get-WinEvent -FilterHashtable @{ LogName=$log; Id=11 } |
  Where-Object { $_.Message -like '*mimikatz*' }

D. Persistence qua Run key

Event 13T1547.001 
Get-WinEvent -FilterHashtable @{ LogName=$log; Id=13 } |
  ConvertTo-SysmonObject |
  Where-Object { $_.TargetObject -match '\\CurrentVersion\\Run' } |
  Select UtcTime, Image, TargetObject, Details

E. Process injection (Remote Thread)

Event 8T1055 
Get-WinEvent -FilterHashtable @{ LogName=$log; Id=8 } |
  ConvertTo-SysmonObject | Select UtcTime, SourceImage, TargetImage, StartFunction

F. Giấu dữ liệu trong Alternate Data Stream

Event 15T1564.004 
Get-WinEvent -FilterHashtable @{ LogName=$log; Id=15 } |
  ConvertTo-SysmonObject | Select UtcTime, Image, TargetFilename, Hash

G. Lệnh PowerShell mã hóa

Event 1T1027 
Get-WinEvent -FilterHashtable @{ LogName=$log; Id=1 } |
  ConvertTo-SysmonObject |
  Where-Object { $_.CommandLine -match '\s-(e|enc|encodedcommand)\s' } |
  Select UtcTime, ParentImage, CommandLine

H. Ai kết nối ra ngoài nhiều nhất?

Event 3Thống kê 
Get-WinEvent -FilterHashtable @{ LogName=$log; Id=3 } |
  ConvertTo-SysmonObject |

08wevtutil.exe – lựa chọn thay thế

Room nhắc wevtutil.exe như công cụ thứ hai. Nó dùng được cả trong cmd.exe và cùng cú pháp XPath.

Mục đíchLệnh
5 sự kiện mới nhất, dạng chữwevtutil qe Microsoft-Windows-Sysmon/Operational /c:5 /rd:true /f:text
Truy vấn file .evtxwevtutil qe C:\Logs\x.evtx /lf:true /q:"*[System[EventID=3]]" /f:text
Liệt kê logwevtutil el
Thông tin log (kích thước, số bản ghi)wevtutil gli Microsoft-Windows-Sysmon/Operational
Xuất log ra filewevtutil epl Microsoft-Windows-Sysmon/Operational C:\Logs\sysmon.evtx

/c = số lượng · /rd:true = mới nhất trước · /f:text|xml = định dạng · /lf:true = đường dẫn là file.
