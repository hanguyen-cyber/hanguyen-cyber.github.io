Windows Event ID cho SOC

Bảng tra cứu nhanh các Event ID hay dùng khi triage và điều tra trên Windows. Bấm vào số Event ID để copy lệnh PowerShell lọc đúng event đó. ★ là những event nên thuộc lòng.

Event IDTên và ý nghĩa với SOCTrường cần xemLưu ý / dấu hiệu đáng ngờ

Logon Type trong 4624, 4625

2Interactive: đăng nhập tại chỗ, ngồi trước máy
3Network: truy cập qua mạng (share SMB, và RDP khi bật NLA)
4Batch: scheduled task chạy
5Service: dịch vụ khởi động bằng tài khoản dịch vụ
7Unlock: mở khóa màn hình
8NetworkCleartext: mật khẩu gửi dạng rõ (IIS Basic Auth)
9NewCredentials: runas /netonly, hay gặp trong lateral movement
10RemoteInteractive: Remote Desktop (RDP)
11CachedInteractive: đăng nhập bằng thông tin lưu đệm khi không kết nối domain

Mã lỗi 4625 trường Status / Sub Status

0xC000006AUser đúng, sai mật khẩu: dấu hiệu brute force
0xC0000064User không tồn tại: dấu hiệu password spraying, dò tên user
0xC000006DLỗi chung, xem Sub Status để biết chi tiết
0xC0000234Tài khoản đang bị khóa
0xC0000072Tài khoản bị vô hiệu hóa
0xC000006FĐăng nhập ngoài giờ cho phép
0xC0000070Đăng nhập từ máy không được phép
0xC0000071Mật khẩu đã hết hạn
0xC0000193Tài khoản đã hết hạn
0xC0000133Lệch giờ giữa máy và domain controller
