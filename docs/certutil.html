1. Definition1. Định nghĩa

certutil.exe is a command-line utility built into every Windows machine, located at C:\Windows\System32\, part of Active Directory Certificate Services. Its original job: view, verify, configure and manage digital certificates and revocation lists (CRL).

certutil.exe là tiện ích dòng lệnh có sẵn trên mọi máy Windows, nằm tại C:\Windows\System32\, thuộc bộ Active Directory Certificate Services. Nhiệm vụ gốc: xem, kiểm tra, cấu hình và quản lý chứng chỉ số (certificate) cùng danh sách thu hồi (CRL).

Analogy: A digital certificate is like the "ID card" of a website, program or server. certutil is the "registry clerk" — it views, cross-checks, backs up and converts the format of those documents.
Ví von: Chứng chỉ số giống "giấy tờ tùy thân" của website, phần mềm hay máy chủ. certutil là "nhân viên phòng hộ tịch" — chuyên xem, đối chiếu, sao lưu và chuyển đổi định dạng các giấy tờ đó.

2. General syntax2. Cú pháp chung

certutil [options] -<command> [parameters]
  • certutil -? — list all commands
  • certutil -? — liệt kê toàn bộ lệnh
  • certutil -<command> -? — see details of one command
  • certutil -<lệnh> -? — xem chi tiết một lệnh cụ thể

⚠ Note: if you type certutil with a parameter but forget to specify a command, it defaults to -dump (read a certificate file). Give it a URL and it looks for a file on disk → ERROR_FILE_NOT_FOUND.

⚠ Lưu ý: nếu gõ certutil kèm tham số mà quên chỉ định lệnh, nó mặc định chạy -dump (đọc file chứng chỉ). Đưa cho nó một URL thì nó đi tìm file trên đĩa → ERROR_FILE_NOT_FOUND.

3. Common valid commands3. Các lệnh hợp lệ thường dùng

Hash a file to check integrity MOST USED

Tính hash kiểm tra toàn vẹn file DÙNG NHIỀU NHẤT

certutil -hashfile C:\path\file.iso SHA256

Supports MD5, SHA1, SHA256, SHA512.

Hỗ trợ MD5, SHA1, SHA256, SHA512.

Analogy: A hash is a file's "fingerprint" — change one byte and the fingerprint changes completely. Compare it against the value the vendor publishes to confirm a downloaded firmware / SPI-AOI installer is intact.
Ví von: Hash là "vân tay" của file — sửa 1 byte là vân tay đổi hẳn. So với giá trị nhà cung cấp công bố để biết firmware / bộ cài máy SPI-AOI tải về có nguyên vẹn không.

View the certificate store

Xem kho chứng chỉ

certutil -store My     # user / machine certificates
certutil -store Root   # trusted root CAs
certutil -store My     # chứng chỉ của user/máy
certutil -store Root   # các CA gốc được tin cậy

Read & verify a certificate file

Đọc & kiểm tra một file chứng chỉ

certutil -dump C:\cert\server.cer     # issuer, validity, algorithm
certutil -verify C:\cert\server.cer   # check trust chain + revocation
certutil -dump C:\cert\server.cer     # người cấp, hạn dùng, thuật toán
certutil -verify C:\cert\server.cer   # kiểm tra chuỗi tin cậy + thu hồi

Convert Base64 ↔ binary (PEM ↔ DER)

Chuyển đổi Base64 ↔ nhị phân (PEM ↔ DER)

certutil -encode input.bin output.txt
certutil -decode input.txt output.bin

4. Downloading a file from a URL4. Tải file từ URL

The -urlcache parameter was made to manage the certificate/CRL URL cache, but since it can "call out to the network and pull a file back", it can also download files. To download correctly you need all 3 pieces:

Tham số -urlcache sinh ra để quản lý cache URL của chứng chỉ/CRL, nhưng vì biết "gọi ra mạng kéo file về" nên cũng làm được việc tải file. Muốn tải đúng, cần đủ 3 mảnh:

certutil -urlcache -split -f http://host/file.bin output.bin
ParameterWhat it doesAnalogy
-urlcacheAllows network calls via the URL cache mechanismOpens the warehouse gate
-fForce — skip the cache, fetch a fresh copyInsist on fresh goods, not leftovers
-splitSplit & write the correct content to the output fileUnpack the goods and shelve them
Tham sốViệc nó làmVí von
-urlcacheCho phép gọi ra mạng qua cơ chế cache URLMở cổng kho
-fForce — bỏ qua cache, tải bản mớiBắt lấy hàng tươi, không lấy hàng tồn
-splitTách & ghi đúng nội dung ra file đíchBóc hàng khỏi thùng, xếp lên kệ

⚠ Without -f → it easily hits the OFFLINE state, only querying the cache instead of downloading fresh. Without -split → the output file may have the wrong binary content.

⚠ Thiếu -f → dễ dính trạng thái OFFLINE, chỉ tra cache chứ không tải mới. Thiếu -split → file đầu ra có thể sai nội dung nhị phân.

5. Blue-team view5. Góc blue team

Why certutil deserves monitoring

Vì sao certutil đáng được giám sát

Because it is signed by Microsoft and present on every machine, certutil is in the LOLBAS catalogue (Living Off the Land Binaries) — legitimate binaries that defenders need to watch for abnormal behaviour, since they can reach the network / encode-decode without installing anything.

Vì là file có chữ ký Microsoft và có mặt trên mọi máy, certutil nằm trong danh mục LOLBAS (Living Off the Land Binaries) — những binary hợp lệ mà phía phòng thủ cần theo dõi hành vi bất thường, vì chúng có khả năng gọi mạng / mã hóa-giải mã mà không cần cài thêm gì.

Analogy: A kitchen knife — a legitimate tool, but if it shows up somewhere odd (certutil pulling an unknown file from the internet into %TEMP%) that's a signal to investigate.
Ví von: Con dao trong bếp — dụng cụ hợp pháp, nhưng nếu xuất hiện ở chỗ lạ (certutil đang kéo file lạ từ internet về %TEMP%) thì đó là tín hiệu để điều tra.

Signs to detect

Dấu hiệu cần phát hiện

  • Process certutil.exe with a parameter containing urlcache + http:// / https://
  • Process certutil.exe có tham số chứa urlcache + http:// / https://
  • Accompanied by a network connection (Sysmon Event ID 3) to an unfamiliar address
  • Kèm network connection (Sysmon Event ID 3) tới địa chỉ lạ
  • An unusual parent process (winword.exe, powershell.exe...)
  • Process cha bất thường (winword.exe, powershell.exe...)
  • Output file written to %TEMP%, %APPDATA%, C:\Users\Public
  • File đầu ra ghi vào %TEMP%, %APPDATA%, C:\Users\Public

MITRE ATT&CK: T1105 (Ingress Tool Transfer), T1140 (Deobfuscate/Decode Files).

MITRE ATT&CK: T1105 (Ingress Tool Transfer), T1140 (Deobfuscate/Decode Files).

Forensic artifact: certutil leaves a cached copy at %LOCALAPPDATA%\Microsoft\Windows\INetCache\... — even if the output file is deleted, the cached copy may remain for tracing.

Artifact forensic: certutil để lại bản cache tại %LOCALAPPDATA%\Microsoft\Windows\INetCache\... — kể cả khi file đích bị xóa, bản cache vẫn có thể còn để truy ngược.
